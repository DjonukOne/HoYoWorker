# 🌟 HoYoWorker

**HoYoWorker** — это легковесное, асинхронное десктопное приложение для автоматизации рутины в играх компании HoYoverse. Программа работает в фоновом режиме (system tray) и самостоятельно собирает ежедневные отметки, а также ищет и вводит новые промокоды.

### Поддерживаемые игры:
- 🗡️ Genshin Impact
- 🚂 Honkai: Star Rail
- 📺 Zenless Zone Zero

---

## ⚙️ Основные функции

- **Авто-отметки:** Ежедневный автоматический сбор наград на сайте HoYoLAB.
- **Умный парсер промокодов:** Программа сама запрашивает актуальные базы промокодов (через API Ennead) и применяет их к вашим аккаунтам.
- **Локальная база данных:** Умная система "истории" промокодов — скрипт запоминает активированные и просроченные коды, чтобы не спамить сервера одними и теми же запросами.
- **Безопасная авторизация:** Встроенный мини-браузер позволяет безопасно залогиниться в HoYoLAB прямо в приложении. Вам не нужно вручную искать и копировать `cookie` файлы.
- **Авто-продление сессии:** больше не нужно перелогиниваться каждые несколько дней. При каждом запуске программа сама запрашивает у HoYoLAB новый токен (см. раздел ниже).
- **Шифрование:** Учётные данные (токены, `stoken`, а при желании — логин и пароль) хранятся только локально в `AppData\HoYoWorker` в зашифрованном виде: данные — алгоритмом Fernet, а сам ключ дополнительно защищён средствами Windows (DPAPI) и привязан к вашей учётной записи Windows.
- **Фоновая работа:** Сверните приложение, и оно продолжит работу в трее, выполняя задачи точно по заданному вами расписанию.

## 🚀 Быстрый старт (Для пользователей)

Вам не нужно устанавливать Python или разбираться в коде. 

1. Перейдите во вкладку **[Releases](../../releases)** в этом репозитории.
2. Скачайте последнюю версию файла `HoYoWorker.exe`.
3. Запустите программу, нажмите «Войти в HoYoLAB» и авторизуйтесь.
4. *(Рекомендуется)* Нажмите «Авто-вход по паролю» и введите логин с паролем — тогда программа сможет полностью перевыпустить сессию, даже если HoYoLAB её отзовёт.
5. Настройте время автоматического запуска. При закрытии окна программа свернется в трей (рядом с часами) и будет работать в фоне!

## 🔄 Авто-продление сессии (почему больше не нужен перелогин)

Раньше программа просто сохраняла cookies, полученные после входа в HoYoLAB. Проблема в том,
что токен `cookie_token_v2` (именно он нужен для **ввода промокодов**) живёт всего несколько дней,
поэтому приходилось заходить в аккаунт заново.

Теперь приложение хранит в зашифрованном виде «исходные данные» для авторизации и **при каждом
запуске запрашивает новый токен**:

| Способ | Что использует | Когда применяется |
| --- | --- | --- |
| `stoken` → `getBySToken` | долгоживущий токен HoYoLAB | если HoYoLAB выдал `stoken` при входе |
| Продление cookie-токена | `cookie_token_v2` | если `stoken` нет, но токен ещё действителен |
| Повторный вход | сохранённые логин и пароль | если токены уже отозваны |

Полученные токены сразу проверяются реальным запросом к API: если способ не сработал,
программа автоматически пробует следующий. Кроме того, токен обновляется перед плановыми
задачами (если он старше 6 часов) и ещё раз — если HoYoLAB отклонил его во время работы.

**Про хранение пароля.** Пароль сохраняется только если вы сами поставили галочку в диалоге
«Авто-вход по паролю». Он шифруется вместе с остальными данными, а ключ шифрования защищён
Windows DPAPI — файлы невозможно расшифровать на другом компьютере или под другой учётной
записью Windows. Если не хотите хранить пароль, просто войдите через браузер: токены всё равно
будут продлеваться, но после полного отзыва сессии потребуется один повторный вход.
Кнопка «Выйти из аккаунта» удаляет и токены, и сохранённый пароль.

*(Если вы захотите добавить программу в автозапуск Windows: нажмите `Win + R`, введите `shell:startup` и поместите ярлык программы в открывшуюся папку).*

## 🛠️ Для разработчиков (Запуск из исходников)

Если вы хотите запустить скрипт напрямую через Python.

**Требования:** 
**Питон:** `Python 3.10+`
**Библиотеки:** `genshin` `aiohttp` `PyQt6` `PyQt6-WebEngine` `cryptography`

Установка зависимостей (версии PyQt6 в `requirements.txt` зафиксированы — см. раздел «Решение проблем»):
```
pip install -r requirements.txt
python check_deps.py
```

**Сборка exe:**
```
build.bat
```
Скрипт сначала проверяет зависимости, затем собирает `dist\HoYoWorker.exe`. Вручную команда выглядит так:
```
pyinstaller --noconfirm --onefile --windowed --icon "icon.ico" --add-data "icon.png;." ^
    --hidden-import PyQt6.QtWebEngineWidgets --hidden-import PyQt6.QtWebEngineCore main.py
```

## 🧩 Решение проблем

### `ImportError: DLL load failed while importing QtWebEngineWidgets: Не найдена указанная процедура`

Так выглядит конфликт версий: `PyQt6` и `PyQt6-WebEngine` собраны с разными библиотеками Qt
(WebEngine всегда отстаёт от PyQt6 на одну минорную версию). В одном процессе оказываются
две Qt — и Windows не может загрузить DLL.

Лечится переустановкой совместимой пары (в том окружении, из которого вы запускаете/собираете программу):
```
pip uninstall -y PyQt6 PyQt6-Qt6 PyQt6-WebEngine PyQt6-WebEngine-Qt6 PyQt6-sip
pip install -r requirements.txt
python check_deps.py
```
После этого удалите папки `build` и `dist` и пересоберите exe через `build.bat`.

Если пересборка не нужна — приложение всё равно запустится: встроенный браузер будет
помечен как недоступный, а войти можно кнопкой **«Авто-вход по паролю»**.
