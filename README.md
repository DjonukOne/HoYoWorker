# 🌟 HoYoWorker

**HoYoWorker** — это легковесное, модульное асинхронное десктопное приложение для автоматизации рутины в играх компании HoYoverse. Программа работает в фоновом режиме (system tray), поддерживает неограниченное количество аккаунтов и самостоятельно собирает ежедневные отметки, а также ищет и вводит новые промокоды.

### 🎮 Поддерживаемые игры:
**Базовые (встроены по умолчанию):**
- 🗡️ **Genshin Impact** (`GENSHIN`)
- 🚂 **Honkai: Star Rail** (`STARRAIL`)
- 📺 **Zenless Zone Zero** (`ZZZ`)

**Модульная поддержка любых других проектов HoYoverse:**
- Программа автоматически распознаёт всех привязанных персонажей на вашем аккаунте HoYoLAB (включая **Honkai Impact 3rd**, **Petit Planet**, **Honkai: Nexus Anima** и др.).
- Через вкладку **«⚙ Настройки»** вы можете самостоятельно добавлять новые игры, менять их короткие теги и подключать сторонние JSON-источники промокодов!

## ⚙️ Основные функции

- **👥 Мульти-аккаунты во вкладках:** Удобный интерфейс в стиле браузера `[⚙ Настройки] [Аккаунт 1] [+]`. Добавляйте сколько угодно твинков в один клик. Для каждого аккаунта можно гибко настроить расписание галочками (⏰ — авто-отметки, 🎟️ — авто-промокоды), а длинные названия вкладок плавно прокручиваются бегущей строкой!
- **🔄 Умный перелогин с автозаполнением:** Токен `cookie_token_v2`, необходимый для ввода промокодов, имеет короткий срок жизни. Программа умеет сама открывать окно браузера перед вводом кодов и автоматически заполнять ваши логин и пароль (даже внутри защищенного `iframe` HoYoLAB) — вам остается лишь нажать «Войти» и пройти капчу, после чего окно закроется само и продолжит активацию.
- **🌐 Умный парсер и локальная БД промокодов:** Скрипт сканирует интернет-источники (по умолчанию API Ennead) и ведёт персональную историю для каждого `UID`, чтобы не спамить сервера уже активированными или истекшими кодами.
- **🎁 Быстрый ввод кодов со стримов:** Специальное поле в настройках позволяет выбрать игру, вставить сразу несколько промокодов через пробел и в один клик активировать их на **всех** ваших аккаунтах.
- **🎨 Кастомизация оформления (CSS):** Полная поддержка пользовательских тем. Экспортируйте стандартный стиль в `.css` файл, меняйте цвета, шрифты или скругления по своему вкусу и импортируйте обратно!
- **🔒 Шифрование и безопасность:** Все куки, логины, пароли и настройки надежно шифруются алгоритмом `Fernet` (AES-128) и хранятся локально в базе SQLite (`%APPDATA%/HoYoWorker`).
- **🚀 Интеграция с Windows:** Встроенный переключатель автозапуска вместе с системой, сворачивание в системный трей и всплывающие уведомления при успешной активации промокодов.

## 🚀 Быстрый старт (Для пользователей)

Вам не нужно устанавливать Python или разбираться в коде.

1. Перейдите во вкладку **[Releases](../../releases)** в этом репозитории и скачайте последнюю версию `HoYoWorker.exe`.
2. Запустите программу, перейдите во вкладку аккаунта и нажмите **«Войти в HoYoLAB»**.
3. Перейдите во вкладку **«⚙ Настройки»**, чтобы:
   - Задать удобное время для сбора отметок и проверки промокодов.
   - Указать логин/пароль для функции автозаполнения при перелогине.
   - Включить галочку **«🚀 Запускать HoYoWorker вместе с Windows»**.
4. При закрытии окна на крестик программа свернется в системный трей (рядом с часами) и продолжит работу в фоне!

> **💡 Совет (Решение ошибки SSL):** Если при сборе отметок возникает ошибка `SSL: WRONG_VERSION_NUMBER`, убедитесь, что средства обхода блокировок (например, *Zapret* или *GoodbyeDPI*) не модифицируют трафик к серверам HoYoverse. Добавьте домены `mihoyo.com`, `hoyoverse.com` и `hoyolab.com` в список исключений вашего DPI-обходчика.

## 🛠️ Для разработчиков (Запуск из исходников)

Проект построен по модульному принципу (каждый модуль отвечает за свою задачу и не превышает 300 строк кода):
* `main.py` — точка входа и инициализация Qt.
* `gui.py` — главное окно, управление вкладками, бегущей строкой, треем и планировщиком.
* `tab_account.py` / `tab_settings.py` / `settings_games_ui.py` — модули пользовательского интерфейса.
* `browser_auth.py` — изолированные профили `QWebEngine`, перехват `v2` куки и JS-инжектор автозаполнения.
* `hoyo_api.py` / `promo_parser.py` — асинхронное ядро работы с API HoYoLAB и парсер промокодов.
* `config.py` / `db_manager.py` — менеджер состояния и шифрованное хранилище SQLite + Fernet.
* `styles.py` — базовые QSS/CSS стили оформления.

**Требования:**
- **Python:** `3.10+`
- **Зависимости:**
```bash
python -m pip install genshin aiohttp PyQt6 PyQt6-WebEngine cryptography
```
Сборка в .exe через PyInstaller:
```bash
python -m PyInstaller --noconfirm --onefile --windowed --icon "icon.ico" --add-data "icon.png;." main.py
```
